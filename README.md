# MiraNote - Pitch Deck & Demo

AI visual journaling. Speak, type, or drop in a photo, and MiraNote turns it into a
finished, editable memory page in about 30 seconds. Live on iOS.

**One-page view (deck + demo video): https://miranote-ai.github.io/miranote-deck/**
